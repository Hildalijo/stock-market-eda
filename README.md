# Stock Market Exploratory Data Analysis

## Overview

This project performs exploratory data analysis on dynamically retrieved
historical stock market data using Python and yfinance.

Six companies from different industries are analyzed:

- Apple
- Microsoft
- NVIDIA
- JPMorgan Chase
- ExxonMobil
- Walmart

## Objectives

The project explores:

- Historical stock prices
- Daily returns
- Cumulative returns
- Trading volume
- Volatility
- Correlations
- Moving averages
- Rolling volatility
- Maximum drawdowns
- Risk vs return

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yfinance

## Key Findings

During the selected analysis period:

- NVIDIA recorded the highest total return at 88.57%.
- NVIDIA also had the highest annualized volatility at 44.21%.
- JPMorgan had the lowest annualized volatility at 24.74%.
- NVIDIA experienced the largest maximum drawdown at 36.89%.
- Microsoft and NVIDIA had the strongest return correlation among the
  analyzed pairs at approximately 0.42.

## Project Structure

stockmarket_EDAhilda.ipynb - Complete EDA notebook

stock_eda_summary.csv - Summary of calculated performance and risk metrics

## Disclaimer

This project is an educational exploratory data analysis of historical
market data. Historical performance does not predict future performance,
and the findings should not be interpreted as investment recommendations.
